# CV Contour Detection Mini Project (OpenCV)

This mini project demonstrates a full edge-to-contour pipeline using OpenCV:

**Grayscale → Gaussian Blur → Canny Edges → Morphological Closing → Contours → Overlay Output**

## Repository Structure
- `notebooks/` → Jupyter notebook demos
- `images/` → input images (use your own/free-to-use images)
- `outputs/` → saved results (edges, masks, contour overlays)
- `docs/` → screenshots/notes
